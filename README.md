# Мобильный пульт для Unitree Go2

Страница для телефона: сверху две камеры, снизу джойстик. Плюс то, без чего
она на мобильном интернете бесполезна — лёгкие копии видео и правки к службам
робота, убирающие задержку.

Делалось поверх готового комплекта («кабинет оператора» на ноутбуке: службы
`<имя>-ctl` — управление и речь, `<имя>-dash` — кабинет, `<имя>-ptt` —
защищённый вход, `<имя>-mediamtx` — раздатчик видео). Если у вас такой же
комплект, всё встанет как есть. Если нет — смотрите [docs/УСТРОЙСТВО.md](docs/УСТРОЙСТВО.md),
там расписано, какие ручки страница использует и что нужно от робота.

**Кабинет на ноутбуке не меняется ни на строку.** Это было прямым требованием:
рабочий инструмент заказчика трогать нельзя. Поэтому страница телефона
отдаётся из защищённого входа, а лёгкие копии камер живут в отдельном
раздатчике, которого кабинет не видит.

## Что умеет страница

**Вкладка «Пульт»**
- Джойстик: вверх-вниз — ход, вправо-влево — поворот (или шаг вбок).
- «ДВИЖ.» — разрешение хода, без него джойстик не работает.
- Большой СТОП и переключатель скорости 65% / 100%.
- Позы: встать, лечь, сесть, встать из сидя, привет, потянуться, расслабить.

**Вкладка «Звук»**
- Сирена: кнопки звуков, которые лежат на роботе, и выключение.
- Рация: держите кнопку и говорите, робот повторяет вашим голосом.
  Звук идёт **потоком**, кусками по 0.25 с, и робот начинает говорить,
  пока вы ещё говорите. Раньше фраза уходила целиком после отпускания —
  задержка не могла быть меньше длины фразы.
- Громкость сирены и рации отдельными ползунками, 0–200%.

**Камеры**
- Две сразу: большая и маленькая в углу, нажатие меняет местами.
  Режимы: «PiP», «две поровну», «одна».
- Кнопка «лёгкое / чёткое»: лёгкие копии 640×360 или полные потоки.
- Подпись с битрейтом, «НЕТ ПОТОКА» если камера пропала, и
  переподключение, когда она вернулась.

**Безопасность движения** (её обеспечивает служба управления, страница только
не мешает): скорость ограничена сервером, сторож мёртвой руки 0.35 с, ход
выключается сам при уходе со страницы, потере фокуса и гашении экрана.

## Чего это стоит на канале

Замеры на нашей собаке (Orin NX, интернет через 4G-роутер):

| | было | стало |
|---|---|---|
| два видеопотока на телефон | 3.4 Мбит/с | **0.58 Мбит/с** |
| команда пульта (пинг 38–50 мс) | 145–186 мс | **27–56 мс** |
| процессор на лёгкие копии | — | 3–6% (аппаратный кодировщик) |

Подробности и метод: [docs/ЗАМЕРЫ.md](docs/ЗАМЕРЫ.md).

## Установка

На самой собаке:

```bash
NAME=shym1 ./install.sh
```

`NAME` — префикс ваших служб (`shym1-ctl`, `shym1-dash`, …). Скрипт:

1. кладёт `mobile.html` в каталог приложения;
2. поднимает второй раздатчик видео и два конвейера лёгких копий;
3. печатает, какие патчи применить к службам вручную.

Патчи в [patches/](patches) применяются человеком — это службы, управляющие
железом, и мы не автоматизируем их подмену:

- `ctl-raciya-gromkost-zaderzhka.patch` — потоковая рация, громкость, TCP_NODELAY;
- `ptt-stranica-telefona-i-zaderzhka.patch` — выдача `/m`, маршрут `/mtx2/`,
  рукопожатие TLS в потоке соединения, TCP_NODELAY.

После установки адрес пульта:

```
https://<адрес робота>:9996/m
```

Сертификат самоподписанный — браузер спросит один раз. **HTTPS обязателен:**
микрофон (рация) браузер даёт только защищённой странице.

## Работа с этой папкой

Папка репозитория — **единственное место**, где живёт рабочая версия. Правим
здесь, отсюда же заливаем на робота, потом фиксируем в git. Две копии (одна
«рабочая», другая «для GitHub») расходятся за неделю, и потом не скажешь,
какая настоящая.

```bash
./залить.sh                 # страницу на собаку (быстро, без sudo)
./залить.sh --видео         # ещё и лёгкие копии камер
./собрать-патчи.sh          # пересобрать заплатки из папки «службы»
git commit -am "что изменил" && git push
```

Адрес и имя собаки задаются перед командой, по умолчанию наши:

```bash
HOST=192.168.1.191 NAME=shym1 ./залить.sh
```

Папка **`службы/`** в git не попадает: там лежат рабочие копии `ctl.py` и
`ptt.py` вместе с их исходниками «до наших правок». Из этой пары и собираются
заплатки. Сам код служб — чужой, он здесь не публикуется.

Скрипт `собрать-патчи.sh` перед выходом проверяет заплатки на пароли, ключи и
адреса робота, и ругается, если что-то похожее туда попало.

## Требования

- Комплект со службами `ctl` (порт 9999) и `ptt` (порт 9996, https).
- MediaMTX для видео.
- Для лёгких копий — аппаратный кодировщик `nvv4l2h264enc`. Есть на Orin NX;
  на Orin Nano блок NVENC вырезан на кремнии, там жать придётся процессором.
- Телефон в одной сети с роботом: Wi-Fi робота, VPN или Tailscale.
  По локальной сети задержка около 2 мс, через 4G — десятки.

## Чего здесь нет

- Кабинета на ноутбуке и остальных служб комплекта: это чужой код, и он не
  менялся.
- Автономности: маршрутов, объезда препятствий, возврата при потере связи.
